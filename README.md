# Hot Burger

نظام إدارة كافتيريا احترافي يعمل بالكامل بدون اتصال بالإنترنت (Offline First).

---

## نظرة عامة

تطبيق Flutter لإدارة وتشغيل كافتيريا Hot Burger. يعمل بنسبة 100% بدون إنترنت باستخدام قاعدة بيانات محلية (SQLite). مصمم بنهج Clean Architecture مع واجهة عربية RTL وتصميم Minimal Modern UI.

---

## الميزات

- **تسجيل دخول** - مستخدم واحد (مدير) بصلاحية واحدة
- **إدارة المنتجات** - إضافة، تعديل، حذف، مع تصنيفات وحالة توفر
- **إدارة التصنيفات** - إضافة، تعديل، تفعيل/تعطيل، حذف
- **شاشة المبيعات** - سلة مشتريات كاملة مع فلترة حسب التصنيف والبحث
- **إدارة الفواتير** - حفظ، عرض، بحث برقم الفاتورة، عرض التفاصيل
- **إدارة المصروفات** - إضافة، تعديل، حذف
- **التقارير** - تقرير يومي وشهري (مبيعات، مصروفات، صافي ربح)
- **النسخ الاحتياطي** - تصدير واستيراد قاعدة البيانات محلياً

## هيكل المشروع

```
lib/
├── core/
│   ├── constants/       # الثوابت العامة
│   ├── database/        # طبقة قاعدة البيانات (SQLite)
│   └── theme/           # ثيم التطبيق والألوان
├── models/              # نماذج البيانات
├── providers/           # إدارة الحالة (Provider)
└── screens/
    ├── auth/            # شاشة تسجيل الدخول
    ├── backup/          # النسخ الاحتياطي
    ├── categories/      # التصنيفات
    ├── expenses/        # المصروفات
    ├── home/            # القائمة الرئيسية
    ├── invoices/        # الفواتير وتفاصيلها
    ├── products/        # المنتجات
    ├── reports/         # التقارير
    └── sales/           # المبيعات
```

## قاعدة البيانات المحلية

يتم استخدام **sqflite** مع 7 جداول:

| الجدول | الوصف |
|--------|-------|
| `users` | حسابات المستخدمين (مستخدم واحد افتراضي) |
| `categories` | تصنيفات المنتجات مع حالة التفعيل |
| `products` | المنتجات مع السعر والتكلفة والتصنيف |
| `invoices` | رؤوس الفواتير |
| `invoice_items` | بنود الفاتورة |
| `expenses` | المصروفات |
| `raw_materials` | هيكل المواد الخام (جاهز للتطوير المستقبلي) |

---

## النسخ الاحتياطي والاستعادة

- **التصدير:** ينسخ ملف قاعدة البيانات `.db` إلى مجلد النسخ الاحتياطي مع التاريخ
- **الاستيراد:** يعرض قائمة بالنسخ المتاحة ويطلب تأكيداً قبل استبدال البيانات الحالية

موقع النسخ الاحتياطي: `[App Documents Directory]/hot_burger_backups/`
